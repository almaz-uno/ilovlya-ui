= Logging in Ilovlya UI

== Installation

The `logger` package is already added to `pubspec.yaml`:

[source,yaml]
----
dependencies:
  logger: ^2.0.2+1
----

== Usage

=== Predefined Loggers

The following loggers are available for different modules in the project:

[source,dart]
----
import 'package:ilovlya/src/utils/logger_provider.dart';

// API calls
AppLoggers.api.i('Request started');

// Media operations
AppLoggers.media.d('Loading media');

// Player
AppLoggers.player.w('Speed changed');

// Settings
AppLoggers.settings.i('Settings saved');

// Downloads
AppLoggers.download.d('Download progress: 50%');

// UI events
AppLoggers.ui.d('Button pressed');
----

=== Logging Levels

[cols="1,3,3"]
|===
|Method |Level |Usage

|`t()` |Trace |Detailed execution tracing
|`d()` |Debug |Debug information (only in debug mode)
|`i()` |Info |Informational messages
|`w()` |Warning |Warnings
|`e()` |Error |Errors
|`f()` |Fatal |Critical errors
|===

=== Logging with Data

[source,dart]
----
// Simple message
AppLoggers.media.i('Media loaded');

// With additional data
AppLoggers.api.i('Response received', {
  'statusCode': 200,
  'count': 42,
  'timestamp': DateTime.now().toIso8601String(),
});

// With error and stack trace
try {
  // some code
} catch (e, st) {
  AppLoggers.api.e('Failed to load', error: e, stackTrace: st);
}
----

=== Example in Riverpod Provider

[source,dart]
----
import 'package:ilovlya/src/utils/logger_provider.dart';

class MediaNotifier extends StateNotifier<AsyncValue<List<Media>>> {
  MediaNotifier() : super(const AsyncValue.loading());

  Future<void> loadMedia() async {
    AppLoggers.media.d('Loading media started');

    try {
      state = const AsyncValue.loading();
      final media = await fetchMedia();

      AppLoggers.media.i('Media loaded', {'count': media.length});
      state = AsyncValue.data(media);
    } catch (e, st) {
      AppLoggers.media.e('Load failed', error: e, stackTrace: st);
      state = AsyncValue.error(e, st);
    }
  }
}
----

=== Example in Media Player

[source,dart]
----
import 'package:ilovlya/src/utils/logger_provider.dart';

class PlayerHandler {
  void play() {
    AppLoggers.player.d('Play requested');
    // play logic
  }

  void seek(Duration position) {
    AppLoggers.player.d('Seek', {
      'position': position.toString(),
      'ms': position.inMilliseconds,
    });
    // seek logic
  }

  void onError(Object error, StackTrace st) {
    AppLoggers.player.e('Playback error', error: error, stackTrace: st);
  }
}
----

== Configuration

=== Debug Mode

In debug mode (`flutter run`):

- Uses `PrettyPrinter` with colored output and emojis
- All logs from `debug` level and above
- Full stack traces on errors
- Timestamps

=== Release Mode

In release mode (`flutter build`):

- Uses `SimplePrinter` without colors
- Only logs from `warning` level and above
- Minimal overhead

== Creating a Custom Logger

If you need a special logger with a unique prefix:

[source,dart]
----
final myLogger = LoggerFactory.create('MyModule');
myLogger.i('Custom logger message');
----

== Recommendations

.During Development
- Use `d()` for debug information
- Add contextual data to logs
- Log all HTTP requests and responses

.In Production
- Log only important events (`i()` and above)
- Always log errors with `error` and `stackTrace`
- Don't log sensitive data (passwords, tokens)

.Naming
- Use brief but clear messages
- Add prefixes for grouping (e.g., "API:", "Player:")
- Use predefined loggers (`AppLoggers.*`)
